Task Priority

Feature guide for TaskFlow users. Sources: Jira SCRUM-1 "Add task priority" and the Confluence page "Task Priority – Functional Specification".

Feature overview

Task priority lets you assign an importance level to a task so you can identify the tasks that need your attention first.

Three priority levels are supported:

  • High
  • Medium
  • Low

All TaskFlow users can create and update task priorities. No additional permissions are required.

Prerequisites

  • You are a TaskFlow user.
  • No additional permissions are required.

How the feature works

Priority Meaning
High The task requires immediate attention.
Medium The task has normal importance. This is the default.
Low The task can be completed when time permits.
  • If you do not specify a priority when you create a task, TaskFlow assigns Medium.
  • When you update a task's priority, the new value replaces the existing one.
  • When you retrieve a task, the response includes its priority.

Procedures

Create a task with a priority

  1. Provide the task title.
  2. Provide a priority value of High, Medium, or Low.
  3. Submit the request to create the task.

Example request:

{
  "title": "Prepare monthly report",
  "priority": "High"
}

Create a task without a priority

  1. Provide the task title without a priority value.
  2. Submit the request to create the task. TaskFlow assigns the task a priority of Medium.

Update the priority of an existing task

  1. Identify the task whose priority you want to change.
  2. Set the new priority to High, Medium, or Low.
  3. Save the change. The new priority replaces the existing value.

Expected results

  • A task created with a valid priority has that priority.
  • A task created without a priority has Medium.
  • After an update, the task returns the new priority. For example, a task changed from Medium to High is returned with High.
  • A task response includes the priority field, for example "priority": "High".

Example response:

{
  "id": 1,
  "title": "Prepare monthly report",
  "completed": false,
  "priority": "High"
}

Limitations and considerations

  • You cannot create custom priority levels. Only High, Medium, and Low are supported.
  • Priority does not change automatically based on a task's due date.
  • When the feature is enabled, existing tasks are assigned Medium priority.

Troubleshooting

Request rejected with an unsupported priority value

TaskFlow accepts only High, Medium, and Low. If you provide any other value, the request is rejected with this error:

{
  "error": "Priority must be High, Medium, or Low."
}

Correct the value to one of the three supported levels and submit the request again.

Note: The functional specification shows the priority value as a field in the request and response bodies. It does not describe the user interface controls for setting priority.
